# Lineup IQ

Guess the hidden players from starting lineups of iconic football matches.

## Features:
- Football pitch UI to clearly understand the lineup.
- Click on any hidden player's card to open guessing section.
- Progressive hints available to correctly guess each player.
  - *Hint #1*: Nationality
  - *Hint #2*: Career path
  - *Hint #3*: Shirt number in that match
- Score system that deducts score if you use hints.
- Copy result in a shareable form.
- Multiple levels available to solve.
- Suggestions are shown when typing player names.

## How to play?
1. Click on any hidden player to start guessing.
2. Use hints if you want.
3. Type the player name in input field.
4. The game will tell you if the player is correct or not.

## Tech stack:
- Vite (React)
- TailwindCSS for styling
- Lucide react/ react-icons for icons
- Shadcn for UI components
